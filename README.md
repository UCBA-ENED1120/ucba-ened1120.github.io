# UCBA ENED1120 Course Website

Official portfolio website for **ENED1120: Engineering Design Thinking II/Technical Thinking II** at UC Blue Ash, Spring 2025.

## About the Course

ENED1120 is a first-year general engineering course that focuses on:
- Engineering design thinking and technical problem solving
- Programming with MATLAB, C, and LabVIEW
- Raspberry Pi 5 hardware development
- Team-based project work
- Version control with Git/GitHub

## Website Features

This website provides:
- **Course Information**: Syllabus, grading policies, and teaching team
- **Lecture Notes**: Weekly presentations and course materials
- **Homework Assignments**: Access to all homework assignments and resources
- **Quiz Information**: Weekly quiz schedule and policies
- **Project Materials**: Comprehensive Raspberry Pi project resources and documentation
- **University Policies**: Academic integrity, disability services, and student conduct
